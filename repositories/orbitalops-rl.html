OrbitalOps-RL

OrbitalOps RL is a reinforcement learning environment for simulating space mission operations. Agents perform tasks like orbit stabilization and navigation, receiving rewards based on decision quality. Built with FastAPI, Gradio, and LLM integration for testing and benchmarking autonomous systems.
